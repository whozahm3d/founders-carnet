# Datasets

Record every dataset here before it is used. `CLAUDE.md` says no dataset is used unless it is listed. For each one, say what the supervisor will ask: what it contains, why it was chosen, and which user input it serves.

Rules that apply to all of them (see the data rules in `CLAUDE.md`):

- External datasets are for profiling and schema design only. None of them trains the deployed re-ranker.
- Age and gender are never matching features.
- Do not store names, birth dates, or contact fields from external datasets.
- Do not redistribute a dataset. Raw data stays out of git.
- No data without consent.

### Roman-Urdu-Parl split

- **Source and link:** Hugging Face `Mavkif/Roman-Urdu-Parl-split` (paper: Alam et al. 2022)
- **License or terms:** Not stated in the dataset card metadata
- **Date downloaded and version:** 2026-10-03
- **What it contains:** 6,407,268 Urdu and Roman Urdu text pairs in files (train 6,365,808, validation 20,719, test 20,741). One row is one aligned pair. The paper headline figure is 6,365,808, which equals the train split in the files. The report states 6,374,678 total (6,333,218 train) — these numbers do not match the files. The source of 6,333,218 is unknown; check the Hugging Face dataset card before updating the report.
- **Why we chose it:** Only large parallel Urdu and Roman Urdu text we found.
- **User input it serves:** Multilingual input (FR-9, FYP-2).
- **How we use it:** Source for the 30 to 50 parallel descriptions per language in the FYP-2 benchmark. Not used in FYP-1.
- **Fields we keep, fields we drop:** Urdu text, Roman Urdu text.
- **Personal data present?** Not expected (general text). Not checked row by row.
- **Where the raw file lives:** fill in per person (a path outside git, for example `data/`)
- **Report section it supports:** Chapter 3, Table datasets; FR-9
- **Owner:** fill in
- **Known problems:** Status: Kept. Row counts disagree with the report (see above). Claim check run 2026-10-17: see ml/notebooks/dataset_claim_check_report.md.
