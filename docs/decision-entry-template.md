# Decision entry template

Copy this into `docs/DECISIONS.md` as a new entry at the top (newest first). Write in plain words.

```
## YYYY-MM-DD: short title

**Context:** What were we doing, and which report section, diagram or table does it touch?
**What we tried:** What was built or tested, and how.
**What we found:** What happened. Include numbers or error messages if there are any.
**Decision:** What changed, and where: the code, the report, a diagram, or the data dictionary.
**Why:** The reason, in one or two sentences.
**Follow-ups:** What else must be updated, and who does it.
```
