# Compliance evaluation

`gold_questions.jsonl` contains 20 authored questions. It preserves their fixed `split` values (6 dev, 14 test) and does not create gold answers. All answerable questions have reviewed chunk mappings; q008 was confirmed to the Iris attachment-list chunk. Retrieval is run on dev only. The test split remains held out.

Run these exact commands from the repository root in PowerShell:

```powershell
$env:PYTHONPATH = (Resolve-Path backend).Path
$env:HF_HUB_OFFLINE = "1"
$env:TRANSFORMERS_OFFLINE = "1"
backend/.venv/Scripts/python.exe -m rag.evaluation.evaluate --model-id sentence-transformers/paraphrase-multilingual-mpnet-base-v2 --model-id intfloat/multilingual-e5-base
backend/.venv/Scripts/python.exe -m pytest rag/tests backend/tests --junitxml=rag/evaluation/results/pytest.xml
backend/.venv/Scripts/python.exe -m rag.evaluation.record_tests rag/evaluation/results/pytest.xml
backend/.venv/Scripts/python.exe -m rag.evaluation.make_report
```

`evaluate` writes `retrieval.csv`, `e2e.csv`, `split_sizes.csv`, `run_metadata.csv`, and `failure_causes.csv` under `rag/evaluation/results/`. The per-question end-to-end CSV includes a `failure_cause` column. Pytest creates `pytest.xml`; `record_tests` turns it into `test_cases.csv`. The report generator reads only the CSVs and writes `RESULTS.md`.

| CSV | Exact command that writes it |
| --- | --- |
| `retrieval.csv`, `e2e.csv`, `split_sizes.csv`, `run_metadata.csv`, `failure_causes.csv` | `$env:PYTHONPATH = (Resolve-Path backend).Path`; then `backend/.venv/Scripts/python.exe -m rag.evaluation.evaluate --model-id sentence-transformers/paraphrase-multilingual-mpnet-base-v2 --model-id intfloat/multilingual-e5-base` |
| `test_cases.csv` | `backend/.venv/Scripts/python.exe -m rag.evaluation.record_tests rag/evaluation/results/pytest.xml` |
| `pytest.xml` (JUnit input, not a CSV) | From the repository root: `$env:PYTHONPATH = (Resolve-Path backend).Path` then `backend/.venv/Scripts/python.exe -m pytest rag/tests backend/tests --junitxml=rag/evaluation/results/pytest.xml` |

Render the Markdown report from the CSVs only:

```powershell
backend/.venv/Scripts/python.exe -m rag.evaluation.make_report
```

This reads only CSV files in `results/` and writes `rag/evaluation/RESULTS.md`. No question gold answers are generated by the harness.
